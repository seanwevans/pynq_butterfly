# Quick start

1. Run `scripts/run_sim_regression.sh`.
2. Build the overlay using the [build guide](build.md).
3. Prepare exact OpenFHE vectors using the [OpenFHE workflow](openfhe.md).
4. Install and execute them using the [board deployment guide](board-deployment.md).
5. Compare measurements with the [benchmark summary](../results/benchmark-summary.md).
